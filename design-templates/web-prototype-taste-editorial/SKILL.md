# Editorial web composition

Explore warm neutral surfaces, expressive editorial headings, quieter body typography, fine dividers and deliberate whitespace. Consider asymmetry, varied content widths and typography-led sections where the material benefits. Avoid imposing a bento grid, pricing block or font ban on every page.

The user brief, existing brand and selected styling mode take precedence over this reference. Use `example.html` to explore the visual language, not to reproduce every section. Adapt typography and colour to available site resources.

For Bricks, follow Pixflow Frontend and the native live-builder guidance: editable elements, reusable classes, appropriate variables, responsive behavior and saved output. Do not introduce an intermediate HTML build unless the user asks for one. For standalone code, use the project stack.

Motion should explain interactions and respect reduced-motion preferences. Review actual image crops, contrast, focus, loading states and responsive layouts; repair observed defects without a numerical design score or prescribed build ceremony.
