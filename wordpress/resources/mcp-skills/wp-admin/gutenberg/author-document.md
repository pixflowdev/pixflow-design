# Gutenberg document authoring

Read the current target document, including unsaved editor changes when present.
An outline or metadata-only response is not the full content. Preserve unrelated
blocks, valid attributes and linked resources when applying local edits.

Use semantic headings and blocks that fit the content. Core paragraph, heading,
list, quote, media, buttons, group, columns and table blocks cover common needs.
Inspect the installed registration for version-specific attributes and nesting.

Native block APIs serialize the document. Inspect editor validity and relevant
front-end behavior, especially for third-party blocks with generated styles or
linked records. Explain actual changes and unresolved issues in the result.
