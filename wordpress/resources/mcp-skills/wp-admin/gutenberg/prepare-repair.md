# Gutenberg repair

Use the actual error and current document to investigate schema, structure,
serialization, media, context or transport failures. Correct the cause and
continue the requested work. There is no fixed model repair count.

Keep the user's meaning and unrelated blocks. Refresh stale state, resolve
missing media and inspect plugin registration when relevant. A failed or empty
serialization is not a request to delete content. If a runtime error remains,
report what failed and what is still intact without claiming completion.
