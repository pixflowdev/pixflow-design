# Create or replace a complete article

Build a coherent semantic outline before emitting blocks. Use one H1 only
when appropriate to the site/editor convention; otherwise begin content
headings at H2 and maintain a logical hierarchy. Prefer paragraphs, headings,
lists, quotes, media, and calls to action that fit the user’s request rather
than adding decorative blocks by default.

For an existing post, read the exact current document even when the request
sounds like replacement. Include one complete non-empty resulting tree and
only post fields the user requested. Keep draft/publish intent explicit.

Use registered core blocks for ordinary content. Use a registered HTML block when it suits the content, and native editable
blocks for ordinary structure. Match the target block schema.

Media must come from evidence-backed attachments. Do not guess IDs or URLs.
