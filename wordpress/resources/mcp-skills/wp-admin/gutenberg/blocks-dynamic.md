# Dynamic and linked-resource blocks

Query, navigation, template, pattern, form and product blocks depend on records,
queries, assets and runtime state beyond their serialized markup. Inspect those
dependencies and use their native APIs for requested changes. Direct tools can
complete linked-resource work in the same run as document editing.

Preserve existing references and attributes outside the requested change.
Editor validity alone does not establish query results, submission behavior,
navigation destinations or front-end styling; exercise the affected behavior.
