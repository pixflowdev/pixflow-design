# Essential Free skills

This directory contains only the four essential Free skills listed as bundled in `wordpress/resources/skill-editions.json`. Keep their guidance and referenced files self-contained. Preserve source and licence credits.

Optional Pro skills belong in the separate Pro repository and its individually downloadable skill library. Do not restore retired community catalogues, templates or premium implementations here.

Personal skills and installed resources are runtime data. Source cleanup must not delete, rename or overwrite them. Retain compatible stored identifiers and read paths for existing content.

Validate changes with the essential guidance guard, focused skill tests and the WordPress package tests. New required guidance must update the manifest and package ownership checks together.
