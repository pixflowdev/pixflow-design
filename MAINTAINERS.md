# Maintainers

Pixflow Design is maintained by Pixflow. This repository contains Free, the shared runtime and the Bridge toolchain. Premium implementation is maintained separately.

Contributors should follow [CONTRIBUTING.md](CONTRIBUTING.md) and the repository's module guidance. Maintainers review changes for functionality, data preservation, compatibility, security and licensing before release.

Use Pixflow's official support/contact channels for private account or security matters. Do not submit credentials, customer data or private operational reports in public issues.
