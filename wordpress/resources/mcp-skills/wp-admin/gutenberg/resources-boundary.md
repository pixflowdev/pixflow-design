# Linked Gutenberg resources

A post's block document can reference synced patterns, templates, template
parts, navigation entities, forms, commerce records and global styles. Updating
markup alone does not update those resources.

Preserve their IDs, references and rendering during ordinary page/post edits.
Pixflow's specialist Site Editor and shared-resource authoring requires its Pro
tools. When available, read the `site-editor/authoring.md` guide. If unavailable,
do not work around it with generic PHP, database writes or content replacement.
WordPress's native editing remains available. Core Gutenberg review, user-data
export and reliability cleanup remain available without Pro.
