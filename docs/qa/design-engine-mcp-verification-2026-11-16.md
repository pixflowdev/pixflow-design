## Changes driven by observed failures

- Bind the first send of an empty saved chat to its owned WordPress conversation. Previously, the plan tools failed before a first build; CLI and API preparation now carry the binding independently of acknowledged history.
- Advertise run-owned batch reads and screenshot tools in MCP discovery instead of making agents guess their names.
- Add `browser.preview` for the saved connected WordPress page or post, including private drafts. Playwright receives a short-lived, header-only grant for one exact document GET. The grant never becomes a login cookie, never follows a redirect and is revoked after capture (with expiration as the cancellation fallback). Other documents, admin routes and writes remain unauthorized.
- Keep screenshot interaction bounded to hover, visibility checks and disclosure controls. Do not expose arbitrary Playwright evaluation. Live edits continue through the existing editor relay, including follower feedback and native Undo.
- Return screenshot images as MCP image content, alongside local evidence paths. Text-only models can opt out. Do not persist another base64 image copy in streamed chat history.
- Return concise preview measurements and disclosure states; retain full evidence in the local JSON file. Document viewport limits and scrolling explicitly.
- Retain complete revision-aware editor styles in `EDITOR-STYLES.md` and `.json`, with a small reference in tool results. A captured Gutenberg response was 193,359 bytes; applying the compact style representation reduced it to approximately 73 KB without deleting underlying style data.
- Reuse API mode's pure bounded result store for MCP. `pixflow_result_read` reads exact nested fields without shell parsing or replaying the original call. Receipt namespaces differ between runs, preventing stale IDs from resolving to unrelated new results.
- Expose Gutenberg's title and excerpt changes as `gutenberg.document`, using native `editPost`, current document revision and Undo. No publication-state or block-content mutation is accepted through this operation. Missing title support previously caused an agent to search for computer-use workarounds.
- Clarify Gutenberg's document revision versus its style revision, and disclose its 100-block nested-tree limit before dispatch.
- Detect touching adjacent Gutenberg column rows as a contextual review observation, and explain that zero child margins can cancel flow-layout gaps. Intentional flush layouts are not automatically called defects.
