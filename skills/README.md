# Essential Free skills

Free bundles four maintained skills:

- `agent-browser`: browser interaction guidance.
- `export-download-debugging`: diagnosing generated file and download problems.
- `web-design-guidelines`: web interface quality guidance.
- `writing-guidelines`: clear, useful written output.

Each folder contains `SKILL.md` and any local references it requires. These files
are bundled so Free does not depend on downloading essential guidance. The
[skills protocol](../docs/skills-protocol.md) describes the compatible format.

Optional Pro skills belong to the separate Pro repository and its download
library. Do not add the retired community/template catalogue here. Personal
skills and installed resources remain user data and are not removed by source cleanup.

Read [AGENTS.md](AGENTS.md) before modifying the bundled list. The edition manifest
and packaging checks must agree with any change.

Keep each skill's source credits and licence. Directory defaults follow the root
[licence](../LICENSE); files with their own licence retain it. Historical removed
catalogue attribution remains in [third-party notices](../THIRD-PARTY-NOTICES.md)
and [references](../docs/references.md).
