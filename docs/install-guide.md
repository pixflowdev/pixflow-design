# Install Pixflow Design

Install the WordPress plugin from [Pixflow](https://pixflow.dev) and follow the
[setup documentation](https://docs.pixflow.dev/plugin/getting-started/).

Free supports your own API connection without a desktop service. Local CLI
connections use the separately installed [Pixflow Design Bridge](https://pixflow.dev/download-bridge).
Provider subscriptions and usage charges are separate.

For source development, follow [QUICKSTART.md](../QUICKSTART.md). Container
maintainers can use the [local Docker harness](deployment/docker.md); it is not
a one-click production installer or a substitute for the WordPress plugin.
