# Bundled routing guidance

This directory contains the essential default router and Web Clone integration metadata. These are runtime guidance, not a downloadable community catalogue.

The default router stays available in Free. Web Clone implementation is owned by Pro. Builds retain the existing `plugins/_official/...` resource paths and serialized IDs so installed resources and saved projects remain compatible.

Do not add community catalogues or premium skill implementations here. Personal resources remain in their existing data locations and are not affected by source retirement.

The `od-default` ID, `open-design.json` filename and schema URI are compatibility identifiers, not product branding. The original author field is retained as attribution. Renaming these requires a separate migration for saved resources.
