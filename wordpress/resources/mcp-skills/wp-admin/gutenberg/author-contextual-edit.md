# Contextual Gutenberg editing

Resolve “the second section”, “after its final paragraph”, “move it back”, and
similar language only against the exact current document. When multiple
matches remain, ask one targeted clarification and bind it to the originating
post, fingerprint, conversation, and source message.

Represent locations with stable evidence: block name, tree path, nearby
heading/text, and occurrence. Do not use a stale client ID as the sole locator
because parsing can regenerate client IDs.

Modify the smallest requested region locally, then submit the complete
resulting tree. Preserve every unrelated block, order, nested child, unknown
valid attribute, caption, class, link destination, and media binding.

Before preparation, confirm the current fingerprint still matches the exact
read. A clarification from another post or older revision cannot continue.
