# Design-system compatibility contracts

These schemas validate saved and personally imported design systems. Keep them even though the bundled brand catalogue is retired. Canonical shared token contracts live in `packages/contracts/src/design-systems/`; do not create divergent copies.

Preserve legacy DESIGN.md-only resources and stored IDs. Validate schema changes through contracts and daemon design-system tests. Do not restore catalogue generation, brand backfill, or community publication tooling.
